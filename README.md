# DWINDIK — Filmmaker & Creative Director

A cinematic portfolio website for Dwindik, featuring immersive animations, video playback, and a minimalist dark aesthetic.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
